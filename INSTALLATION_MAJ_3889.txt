MISE A JOUR PROJECT TERRIFIC - BUILD 3889 (The Kortz Center Heist)

Installation (ce zip est le serveur COMPLET) :
1. Arreter le serveur et sauvegarder l'ancien dossier.
2. Remplacer l'ancien dossier du serveur par le dossier ProjectTerrific-main de ce zip.
3. Mettre a jour les artifacts FXServer (les anciens refusent la build 3889).
4. Redemarrer.

Base de donnees : RIEN a faire.
- Les voitures (jeu de base, drift, Megane) sont declarees dans qb-core/shared/vehicles.lua, pas en base.
- Quand un joueur achete une voiture, qb-vehicleshop l'ecrit tout seul dans la table player_vehicles.
- Project-Terrific-SQL/ProjectTerrific.sql n'a pas change : a importer uniquement pour une installation neuve.
