MISE A JOUR PROJECT TERRIFIC - BUILD 3889 (The Kortz Center Heist)

Installation (ce zip est le serveur COMPLET) :
1. Arreter le serveur et sauvegarder l'ancien dossier.
2. Remplacer l'ancien dossier du serveur par le dossier ProjectTerrific-main de ce zip.
3. Mettre a jour les artifacts FXServer (les anciens refusent la build 3889) :
   tools/serveur/maj_fxserver.sh (Linux) ou maj_fxserver.ps1 (Windows), ou le reglage de version du panel
   de l'hebergeur. Mode d'emploi : tools/serveur/LISEZMOI.md.
4. Redemarrer.

Base de donnees : RIEN a importer a la main.
- Les nouvelles tables (properties, properties_decorations, pt_gangs..., pt_multijob) sont creees automatiquement au premier demarrage.
- Les colonnes ajoutees aux tables existantes (properties : serrure, next_rent, impayes ; pt_gangs_settings : flotte)
  sont aussi ajoutees automatiquement.
- Les voitures (jeu de base, drift, Megane) sont declarees dans qb-core/shared/vehicles.lua, pas en base.
- Quand un joueur achete une voiture, qb-vehicleshop l'ecrit tout seul dans la table player_vehicles.
- Project-Terrific-SQL/ProjectTerrific.sql n'a pas change : a importer uniquement pour une installation neuve.

Contenu :
- server.cfg : sv_enforceGameBuild 3889
- qb-core/shared/vehicles.lua : 899 vehicules (tout le jeu jusqu'a 3889, hors trains/remorques)
  + 27 versions drift et 20 voitures tuner en vente a l'Import Vehicle Shop (port)
- qb-vehicleshop : showroom du port corrige + protection contre les modeles manquants
- qb-platescan : vehicules de police du jeu
- bob74_ipl 2.7.1 : interieurs des DLC 2023-2026

- [vehicules]/mers18 : Renault Megane 4 RS (2018) convertie pour FiveM, vendue 75 000 a l'Import Vehicle Shop
  (kit de tuning relie et passe en id 1501, entete du .ytd reconstruit). Categorie [vehicules] activee.
- tools/vehicules : extraire_rpf.py (convertit un dlc.rpf solo) + verificateur des voitures addon (bodykits, pieces moteur, conflits) - voir LISEZMOI.md

- [immobilier]/qbx_properties : maisons, entrepots, villas (shells, IPL, MLO). /createproperty (agent immobilier ou admin).
